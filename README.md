# ✦ Mystery Box

An interactive 3D experience built around a simple question:

**What's inside the box?**

A small experiment with 3D, physics, animation and playful interaction — open the box, discover what's inside, and throw the objects around.

[Live Demo](https://mystery-box-orpin.vercel.app/)

---

## ✦ About

Mystery Box is a creative coding project exploring how a simple interaction can turn into a small interactive world.
The experience starts with a closed box. Click it to open it and reveal a collection of objects floating in a small universe.
Once revealed, the objects can be grabbed, dragged and thrown around.
The project combines 3D graphics with physics-based interaction and a responsive interface.

## ✦ Features

- Interactive 3D box
- Animated box opening sequence
- Physics-based objects
- Drag & throw interaction
- Custom 3D models
- Dynamic star field
- Mouse parallax
- Custom glowing cursor
- Responsive layout
- Animated typography and UI states

---

## ✦ Tech Stack

- **Three.js** — 3D scene, models, lighting and rendering
- **Cannon-es** — physics simulation and object interaction
- **GSAP** — animations and transitions
- **Blender** — custom 3D models
- **JavaScript**
- **HTML / CSS**

---

## ✦ Interaction

**1. Click the box**

The box opens and reveals the objects hidden inside.

**2. Discover**

The background transforms into a small star-filled universe.

**3. Play**

Grab any object and move or throw it around.

---

## ✦ Process

The project started as an experiment to learn Three.js and gradually evolved into a more complete interactive experience.

The main focus was on finding a balance between:

- physical interaction
- visual atmosphere
- animation
- simplicity

Rather than building a complex interface, I wanted the interaction itself to be the main part of the experience.
